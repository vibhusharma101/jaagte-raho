Awake while Claude works. Asleep when it's done.

A Claude Code plugin. Give Claude a long task and walk away: your computer won't sleep mid-task, and sleeps normally once Claude is idle. No config.

Uses each OS's own keep-awake lock, switched on and off by Claude Code's hooks.

What it does

  • Stays awake while Claude works, background agents included
  • Sleeps again within seconds of Claude finishing
  • Lets go if Claude crashes: nothing left holding it awake
  • Handles many sessions: awake while any one is working

What it doesn't do

  • Stop sleep when you close the lid: that's your OS lid setting
  • Keep it awake while Claude sits idle, even with sessions open
  • Anything for Claude Code on the web: that runs in the cloud
  • Need admin rights or config: there's nothing to set up
