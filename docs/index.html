Your laptop stays awake while Claude works. Then it sleeps.

Give Claude a two-hour task and walk away. jaagte-raho keeps your computer from sleeping while Claude is working, and lets it sleep normally the moment Claude is done. No config, no admin rights, nothing to remember to switch off.

The problem

Sleep mode doesn't know Claude is busy.

Your OS sees no mouse or keyboard input and puts the machine to sleep, which stops the task with it. Keeping it awake all the time fixes that but drains your battery. jaagte-raho keeps it awake exactly as long as Claude is working.

What you get

Install it once and forget about it.

Awake only while working

Held while a turn runs, including background agents and tasks that keep going after the turn ends.

Sleeps again by itself

Within about 2 seconds of Claude finishing, or about 60 seconds after you interrupt a turn.

Safe if something crashes

The lock is tied to the Claude process. If Claude exits or crashes, the OS releases it. Nothing is left holding your machine awake.

Many sessions at once

Each session holds its own lock. The machine stays awake while any of them is working, and four finished sessions left open overnight still let it sleep.

macOS, Windows, Linux

Uses each OS's own keep-awake API. Nothing extra to install, no admin rights. Tested in CI on all three.

Never fails silently

Every session starts with a one-line check that the lock actually works on this machine. If it doesn't, it tells you why.

How it works

A few hooks and the OS's own lock.

The hooks only create or delete a flag file, so your prompts are never slowed down.

SessionStart

Finds the Claude process and starts a small background watcher for this session.

UserPromptSubmit

Marks the session busy. The watcher takes the keep-awake lock.

Stop · idle_prompt

Clears busy once no background tasks are left. The lock is released and the machine can sleep.

SessionEnd

Stops the watcher. If Claude crashes instead, the OS cleans up anyway.

macOScaffeinate -i -w <claude pid>
Linuxsystemd-inhibit --what=idle:sleep
WindowsPowerSetRequest

Run /jaagte-raho:status any time. It lists every session by folder and last prompt, and whether the lock is really held.

FAQ

Good to know

Does it stop the laptop sleeping when I close the lid?

No. The lid follows your OS lid setting, not the idle timer. On Windows, set Power Options → "Choose what closing the lid does" → Do nothing. On macOS, closing the lid sleeps the Mac unless it's on power with an external display.

What happens while Claude waits for me to approve a tool?

It stays awake, on purpose. The turn isn't over, and if you approve from your phone via Remote Control, a sleeping laptop couldn't continue.

Does it drain my battery?

Only while Claude is working, which is when you want the machine awake. Once Claude is idle, normal sleep comes back. On Windows, set JAAGTE_RAHO_DISPLAY=0 to let the screen turn off while it works.

Do I need it for Claude Code on the web?

No. Cloud sessions run on Anthropic's servers. This is for local sessions: terminal, IDE and Remote Control.

What do I need installed?

Claude Code with plugin support. On Windows, Git Bash (already required by Claude Code) and Windows PowerShell. On Linux, systemd.
